# JavaScript Hangman Game

A classic word-guessing Hangman game built from scratch using pure JavaScript. This project focuses on DOM manipulation, array handling, and event-driven programming.

**Live Demo:** [View Project Live](https://mostafaosman9439.github.io/Hang-Man-Game/)
---

## Features

* **Dynamic Word Generation:** Selects random words from predefined categories.
* **Interactive On-Screen Keyboard:** Users can click letters to guess the hidden word.
* **Game Status Tracking:** Tracks wrong guesses, updates the Hangman drawing/counter, and handles win/lose states.
* **Clean UI:** Styled beautifully to ensure a fun user experience.

---

## Tech Stack Used

* **HTML5:** Game layout structure and container elements.
* **CSS3:** Custom styles, keyboard layout (Flexbox/Grid), and game-over overlays.
* **JavaScript (ES6):** Core game logic (Arrays, Loops, Event Listeners, Conditionals, and String Manipulation).
